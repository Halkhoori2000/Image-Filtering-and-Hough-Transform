Implementation Details

myImageFilter Convolution

Zero-padded 2D convolution implemented from scratch. Applies any odd-dimension kernel to a grayscale image pixel by pixel without using MATLAB's built-in conv2.

myEdgeFilter Edge Detection

Gaussian smoothing → Sobel gradient magnitude and orientation → non-maximum suppression along gradient direction (0°, 45°, 90°, 135°) to produce thin edges.

myHoughTransform Hough

For each edge pixel above threshold, votes across all θ values and computes ρ = x·cos(θ) + y·sin(θ). Accumulates votes in an (ρ, θ) Hough space matrix.

myHoughLines Peak Extraction

NMS on the Hough accumulator to suppress non-peak bins. Flattens and sorts by vote count; returns the top-N (ρ, θ) pairs corresponding to dominant lines.

myHoughLineSegments EC

Extension: converts infinite Hough lines into finite line segments by walking along each detected line and grouping connected edge pixels with configurable gap tolerance.

Parameters

σ = 2 (Gaussian blur), threshold = 0.3 (edge binarisation), ρ resolution = 2 px, θ resolution = π/90 rad, nLines = 50 (peaks extracted from accumulator).
